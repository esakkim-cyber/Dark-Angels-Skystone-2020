# FTC Skystone Robot Control System

This project is based on the FIRST Tech Challenge (FTC) SDK and was developed for the SKYSTONE robotics competition season. The application controls both autonomous and tele-operated robot functions using Java and Android Studio.

## Features

- Autonomous Robot Navigation
- Tele-Operated Control Modes
- Sensor Integration
- Motor and Servo Control
- Computer Vision Support
- TensorFlow Object Detection
- Vuforia Localization
- Android-Based Robot Controller

## Technologies Used

- Java
- Android Studio
- FTC SDK
- TensorFlow Lite
- Vuforia
- Robotics Programming

## Purpose

The goal of this project is to provide a complete robotics control framework for FTC competition robots, enabling autonomous actions, real-time driver control, and advanced sensor-based navigation.
